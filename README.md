📈 FinanScribe: Advanced Financial Forecasting & Scalable ML Architecture
FinanScribe is a high-performance financial analysis platform engineered with a modular Object-Oriented Programming (OOP) approach. It integrates Deep Learning (PyTorch), statistical forecasting (FB Prophet), and Generative AI (Gemini 3-Flash) to provide actionable insights into stocks, commodities (Gold, Silver, Crude Oil), and forex markets.


Link : https://ai-financial-analyzer-dao9ilbkgbbd26bmxp4zob.streamlit.app/

🚀 Key Engineering Highlights
Scalable Software Architecture: Built using Abstract Base Classes (ABC) to ensure high maintainability. The system follows SOLID principles, allowing seamless integration of new asset classes (e.g., Cryptocurrencies).

Advanced Hybrid ML Models:

PyTorch (ANN): Custom Artificial Neural Networks designed to detect non-linear price patterns.

FB Prophet: Statistical time-series modeling to account for seasonality, trends, and market cycles.

LLM Reporting: Integrated with Google Gemini 3-Flash to transform raw technical indicators into professional, human-readable financial reports.

Version Control (Git): Developed with a disciplined Git workflow, ensuring a clean commit history and efficient version tracking throughout the development lifecycle.

Containerization: Fully Dockerized to guarantee "write once, run anywhere" portability, solving dependency conflicts for heavy libraries like Torch and Prophet.

🛠️ Tech Stack
Language: Python 3.11

Framework: Streamlit

AI/ML: PyTorch, FB Prophet, Google Gemini AI

Data Science: Pandas, NumPy, YFinance, Matplotlib

DevOps: Docker, Git, Streamlit Cloud

📂 Project Structure
AbstractClass.py / AbstractOil.py: Define the core interfaces for all financial assets.

stock_market.py, gold.py, crude_oil.py: Implementation of data processing and ML modeling for specific assets.

ui.py: The presentation layer managing user interaction and data visualization.

Dockerfile: Configuration for containerized deployment.


📦 Installation & Deployment
Running with Docker
Deploy the entire stack with a single command:

Bash
docker build -t finanscribe .
docker run -p 8501:8501 finanscribe
Local Setup
Clone the repo: git clone https://github.com/emreocak-tech/financial-analysis-platform

Install dependencies: pip install -r requirements.txt

Environment Variables: Set up your .env file with API_KEY, GOOGLE_GEMINI, and local dataset paths.

Run: streamlit run ui.py
